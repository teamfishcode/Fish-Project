Code & Methodology

The purpose of our Python notebook is to investigate whether heart rate can be extracted automatically from microscope images of freely swimming zebrafish larvae. The current method uses image processing to estimate the position of the heart and Fourier analysis to identify periodic changes in image intensity.

The notebook is written in Google Colab using OpenCV for image processing, NumPy for numerical analysis and Matplotlib for plotting.

Image Analysis Workflow

  1. Load microscope images
  2. Detect potential eye positions
  3. Estimate the heart region
  4. Extract mean pixel intensity
  5. Apply a Fast Fourier Transform
  6. Estimate heart rate

1. Image loading and sampling

The notebook reads TIFF images from a shared Google Drive folder. Alternate frames are selected to reduce the amount of data read from Drive. The code assumes an original sampling rate of 30 frames per second, giving an effective sampling rate of 15 frames per second. This assumption must be checked against the acquisition settings.

2. Eye detection

Grayscale images are thresholded to isolate dark regions. Contours are filtered by area and their centres are calculated using image moments. Two candidate eye positions are used to estimate the midpoint between the eyes.

3. Heart region of interest

The notebook places a 40 by 40 pixel region of interest approximately 150 pixels below the estimated eye midpoint. This allows the region to follow some movement of the fish, although rotation and changes in orientation are not yet accounted for. If eye detection fails, the current implementation uses a fixed fallback region.

4. Intensity signal

For each selected image, the mean intensity within the region is recorded. Contraction and relaxation of the heart may produce periodic changes in this signal. However, movement, blood flow and changes in illumination can also affect intensity.

5. Fourier analysis

A Fast Fourier Transform (FFT) converts the intensity time series into a frequency spectrum. The algorithm searches for the strongest component between 1 and 4 Hz, which is treated as a candidate heartbeat frequency rather than a confirmed measurement.

Heart rate (BPM) = 60 × peak frequency (Hz)

For example, a peak at 3.62 Hz would correspond to 217.2 beats per minute. This value is an illustration from the notebook commentary, not a validated result from the saved execution.

Applications and Benefits

If validated, this approach could reduce the need to count heartbeats manually across large image datasets. It could also support comparisons of cardiac activity across experimental conditions while avoiding the potential effects of tranquillisation on the measurement.

The method provides a starting point for combining automated image analysis with physiological measurements and could be extended using machine learning to improve anatomical localisation.

Running the Notebook

  1. Open the notebook in Google Colab.
  2. Mount Google Drive and change the image folder to an accessible directory containing sequential TIFF files.
  3. Confirm the acquisition frame rate and adjust the effective sampling rate.
  4. Run the analysis and inspect the resulting frequency spectrum.
  5. Check that the detected region covers the heart and compare the estimate with a manual measurement.

The original image dataset is not included in the notebook. Access to suitable images is required to run the analysis. The saved notebook execution currently contains an error caused by the absence of loaded frames.

Limitations and Further Development

The current notebook is a prototype based on classical image processing, not a trained machine learning model. Its accuracy depends on reliable eye detection, visibility of the heart and consistent sampling.

  • Improve localisation so the heart region follows fish rotation.
  • Identify and reject frames where detection fails.
  • Account for missing frames and reduce unwanted signal drift.
  • Validate estimates against manual heartbeat counts across multiple larvae.
  • Investigate segmentation models to improve anatomical tracking.
